MCUHome package mirror

This host serves a copy of the MCUHome package registry: a plain file tree of signed documents and package files. Every directory below is browsable, and the whole tree can be copied.

Which mirrors a source may be fetched from is not decided here — it is stated in that source's signed mirror list, which packages.mcuhome.org serves. That page also explains what the registry is, how a copy of it is verified, and shows what is published.

    Copying the whole tree

    A mirror is a copy of the tree, with no path rewriting and no per-mirror layout. This one exports it read-only over anonymous rsync:

    rsync -a rsync://this-host/registry/ ./registry/

    Append a source's name to pull one source instead of all of them. registry is the module name a mirror set up with the deployment roles of mcuhome-packagetool uses; another operator may have chosen a different one, and rsync rsync://<host>/ lists what a host exports.

    Whatever it was copied from, a copy is worth exactly as much as the original: what makes a source trustworthy is inside it. Verify it with the reference verifier against a root anchor you already hold — verify.py <source> --anchor <anchor.json> — never by trusting the host it came from, this one included.
